# Line icons

Lucide supplies the global 1.75px line style. Existing Phosphor and Hugeicons imports resolve through tsconfig aliases. The small directional hover response is 250ms and follows reduced-motion preferences. Legacy Phosphor weight values are accepted but do not change the shared stroke width.

Run npm run icons:export to regenerate 24px static SVGs in public/icons/line. icon-map.json is the shared name map.
