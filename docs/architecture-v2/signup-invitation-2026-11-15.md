# 注册后的首次体验

## 流程

注册成功并取得会话后统一进入 `/discover`。需要邮箱验证的账户先显示确认邮件提示，经 `/auth/callback` 交换会话后进入同一页面。已有账户仍按原登录目标进入瀑布流。

新注册账户写入 `signup_invitation_version: 1` 和 `signup_invitation_seen: false`。首次欢迎以这两个独立字段识别，不依赖问卷、个人资料或旧 onboarding 是否完成，因此已有账户不会因旧资料未完成而重新进入引导。

新注册用户进入 Discover 后保留商品瀑布流，并自动展开底部 AI 助手小窗。聊天区显示欢迎语「欢迎来到 Omnilink。我可以陪你发现好物、整理灵感，也可以聊聊你想改善的事。」欢迎语下方保留「形象助手」和「先逛逛」两个操作，直接显示在同一条助手消息中。页面不再单独显示邀请面板。欢迎语只在界面显示，不调用模型；用户也可直接在现有输入框输入或上传内容，后续沿用原助手链路。小窗可收起，也可全屏展开。

欢迎语显示后写入账号状态，避免刷新后重复出现。状态保存失败时账号仍保持未读，下次访问会再次自动展开。开发预览只展示该状态，不写入账号状态。

旧的首次资料设置表单不会自动打开，问卷也不再自动启动。识己展示样品不出现在正式用户的瀑布流。

## 验证

20 项自动化测试通过：注册有/无会话分流、验证回跳、安全重定向、网络异常、已有账户登录、首次邀请与资料完成状态独立。

隔离 Chrome 浏览器验证 1200px 与 390px：先展示 35 张目录卡片，随后出现邀请；先逛逛可关闭，刷新不重复；购物偏好可以打开和暂停；没有页面异常与横向溢出。手机启用减少动态效果。

进一步验证：提交答案后保存，暂停再打开停留在同一题；逐题跳过到完成状态后可返回瀑布流；直接输入可收到助手回复。浏览器助手回复使用本地拦截夹具，未向模型服务发送请求；注册与邮箱回跳测试使用认证夹具，未创建真实云端账号或发送邮件。

## 设计交付检查

- Hard Gate PASS：两种屏宽无横向溢出或页面异常；新按钮均有实际操作；沿用既有品牌资产和真实目录，无虚构服务或数据。
- Purpose Gate PASS：现有瀑布流承载内容，局部邀请承载首次问题；单一短时出现动效用于提示新状态，减少动态效果时关闭。
- Liveliness PASS：沿用 Omnilink 冷白底、大图和黑色操作按钮；能量 1、节奏 1、动态 1，主要焦点为提问，背景内容保持可浏览。
- Craftsmanship PASS：测试覆盖跳过、暂停、续答、完成、刷新、失败和普通登录；TypeScript 与相关新增文件 ESLint 检查通过。按 React 检查表复核效果清理、账号隔离、可读控件名称与功能完整性。

本轮未部署 Vercel，未修改云端认证设置，无新增数据库迁移。

## 邀请材质与侧边栏修订

按用户页面批注，邀请面板与两个操作复用聊天输入栏的 `LiquidGlass` 材质，按钮统一 112×44px、同款圆端轮廓。修复嵌套玻璃对白色 `color(srgb 1 1 1 / alpha)` 的亮度解析，防止白底误判成深色造成白字低对比。

侧边栏移除 850ms 宽高与输入栏位置过渡、90ms 显示延迟；开合时不再测量全量卡片或执行 900ms 模糊缩放。抽屉保持挂载，隐藏时停用 Escape 监听，关闭后焦点回到入口。

本机隔离 Chrome 在 569×633、1200×633 各开合五次，点击至完整展开样式生效约 7–38ms。该数值是开发环境中到下一渲染帧的测量，不代表生产设备的性能保证。确认没有开合卡片动画、没有横向溢出和页面异常，Escape 关闭正常。测试报告和截图位于 `/private/tmp/omnilink-glass-sidebar-review/`。

修订交付检查：材质、形状和动效符合本次明确要求；两操作继续可用，问卷回答保存、暂停续答、完成返回与直接对话回归通过；玻璃颜色解析测试通过，TypeScript 与修改文件 ESLint 检查通过。

### 侧边栏过渡调整

根据后续反馈，将纯瞬时开合改为 220ms 的玻璃裁切展开，内容配合 180ms 的 5px 到 0px 模糊与轻微位移。没有恢复宽高补间、全量卡片测量或瀑布流模糊动画；显示不设延迟，快速反向操作可连续衔接。减少动态效果时仍立即切换。569px、1200px 浏览器检查通过，开合时卡片动画数为零，没有页面异常或横向溢出。

### 默认处理入口

输入栏移除回答模型、检索和向量菜单，仅保留不可点击的「自动」状态，避免无实际选择的按钮。原有配置集中到侧栏「设置 → 高级设置」，默认折叠；应用后继续通过现有 Context 发送模型和检索参数，不增加新深度模式或自动模型调度策略。

569px 与 1200px 浏览器验证：旧模型入口不存在；高级设置可展开、修改并应用；关键词检索禁用向量选项；拦截的助手请求包含实际选择的模型及检索模式；输入与模拟回复正常，无页面异常和横向溢出。TypeScript、新增及相关侧栏文件 ESLint 与 diff 检查通过。

### 设置简化为单个 Key

按最新页面批注，设置页移除高级设置，只保留一个 DeepSeek API Key 输入框、保存与连接状态。后台既有模型/检索配置没有通过设置页开放。1108px 暗色浏览器检查：无高级设置和下拉配置；空输入禁止保存；使用虚拟 Key 与拦截接口验证保存反馈及清空输入，没有提交真实凭据。TypeScript、侧栏 ESLint 与 diff 检查通过。

### 注册入口改用最新个人助手

首次邀请中的「探索偏好」改为「个人助手」。点击后启用用户提供的 personal-appearance 1.6.0 包（兼容应用标识 personal-advisor），打开对话卡片并发起「开始个人助手」请求；后续回复继续携带该 Skill。注册入口不再直接打开购物偏好问卷，「先逛逛」保持可用。

390px、1108px 浏览器检查通过：旧入口和购物偏好问卷没有出现；启动与后续消息均带正确 Skill 标识；没有页面运行异常。回复使用本地拦截夹具，未调用真实模型。TypeScript、邀请组件 ESLint 和 diff 检查通过。
