# 个人助手 Skill 替换

来源为用户提供的 personal-appearance.zip，包版本 1.6.0。替换 .agents/skills/personal-advisor 中的旧内容，保留参考资料、数据、示意图和脚本。展示名统一为「个人助手」，原有应用标识保留以兼容已启用用户。

Skill 主文档只维护一份，服务端按主题加载参考文件。文字对话和图片分析通过显式 skillId 选择文档，不接受客户端提供的任意文件路径或系统提示。已有基础助手及购物偏好流程继续各自运行。

激活状态保存在当前页面的会话映射中：同一会话连续使用，其他新会话默认为未启用；可手动移除。浏览器刷新后需要重新选择，未增加跨设备 Skill 会话状态存储。

运行时没有开放包内 Python 执行和成分校验工具；通过接入说明约束模型使用可用的文字选项回退，不能虚称已执行脚本、校验安全性或读取现行法规。没有在本轮执行用户包内脚本。按钮式多轮选择器没有新增专用渲染协议，采用包内定义的文字选项回退。

41 项相关测试通过，覆盖文本与图片请求加载、未知 Skill 拒绝、普通对话及既有路由回归。TypeScript 与新增服务端模块和相关注册表/侧栏 ESLint 检查通过；助手路由保留原有 any 类型警告。

浏览器使用隔离上下文和拦截的模型回复，确认附件菜单选择、连续两轮、手动移除及侧栏启动；请求标识依次为 personal-advisor、personal-advisor、未启用。没有调用真实模型、处理真实人像或发送邮件。

本机 localhost:3000 同时存在另一套临时页面预览。验收使用原 Omnilink 服务的局域网地址，并仅在隔离浏览器中启用该本地源的安全上下文能力，以便运行现有 crypto.randomUUID。未停止其他服务，未改变实际站点安全设置。
