# 10 实施优先级与放行条件

【假设】以下是待确认的实施计划。优先级围绕是否阻塞目标能力。每个阶段先通过与所涉风险对应的隔离环境验收。

| 顺序 | 交付范围 | 放行条件 |
| --- | --- | --- |
| 0 审核确认 | 确认七层修订、请求与结果事件、权威主体、公开投影和记忆版本合同。登记需要先决策的 ? 项 | 批准 [修订图](09-recommended-architecture.md) 和首期范围。对目标环境迁移与授予建立可复查基线 |
| 1 P0 权限与记忆前置 | 设计并验证公开投影和私有草稿/素材隔离。将评测、提案、确认修订和正式快照分开。冻结旧记忆来源判定与迁移规则 | 匿名与非成员读不到草稿和私有对象。评测、模型或行为候选无法激活长期记忆。确认、撤销、拒绝与删除一致。[SEC-01](07-security-performance-review.md#sec-01-p0-公开帖子行与私有草稿共表)　[MEM-01](03-context-memory-review.md#mem-01-p0-长期偏好的确认门槛缺失) |
| 2 P1 最小闭环 | 统一事件、身份与预算准入、请求幂等、轻量语义和受限降级。商品关键词分页作为首个发现切片，普通答复和明确 UI 操作走独立短路径 | “沙发”直接出首批 20 件或真实较少数量，可稳定续取。普通问答不用拉全目录和偏好档案。重发不会重复产生模型动作或助手消息 |
| 3 P1 个性化与索引 | 接已确认快照、会话过滤及证据版本。拆开在线召回与 BGE 索引更新，验证发布回查、币种和否定约束 | 缺个人上下文可出公共结果。下架和撤销在下一轮生效，索引任务并发时不丢新版本，向量失败可回到关键词 |
| 4 P1 有限 Workflow | 先选一条跨资料对比或多步任务验证 Mastra。按需要接私有附件与授权工具。仅在长任务证据充分时引入 worker 与持久执行 | 工具越权拒绝，证据可复核。超时、进程重启、重投和取消有确定结果，费用在预算内。可对照普通 TypeScript 的效果 |
| 5 P2 产品试点与扩域 | 试验自适应页量、非阻塞问答和多样性，增加一个独立内容或服务类型。按负载决定缓存、队列、观测与部署 | 稀缺供给、账户切换、缓存撤回和首屏指标通过。对照组证实互动或质量收益。供给、内容安全及来源治理达标 |

## 迁移与回滚建议 【假设】

1. 盘点迁移、角色、Data API 授予、存储桶和当前写入者。对照旧部署记录确认暂缓的订单迁移及其依赖，生成单独的 V2 迁移范围。以代表账号和合成数据在隔离环境重现 P0 风险。对已发布内容增加公开投影和私有草稿结构，先验证字段级拒绝，再切换读取。发现实际暴露时优先收敛可见范围和衍生索引。[数据库部署记录](../../architecture/database-deployment.md#L3)
2. 增加个人上下文修订、评测尝试和提案结构。回填保留来源、原 ID 和确认状态。无法证明确认的历史结果先放历史或待确认区。记录可对账的源版本和目标修订。对一次迁移键进行幂等回放验证。
3. 暂时做双读比较并记录差异，保持一个权威写入者。通过适配层把旧客户端命令送至新合同。切换后冻结旧的读时搬运和直写入口。查询和异步任务按新权限、实体与上下文版本重新校验。
4. 用路由开关逐步放量。出现问题可恢复旧的公开展示或关闭高风险功能，保留新版记忆与发布修订。回滚不得恢复草稿公开权限或自动激活未确认记忆。清理旧结构前确认兼容窗口、备份和删除范围。

## 验收场景

| 场景 | 可验证结果 |
| --- | --- |
| 公开内容草稿 | 匿名和非成员用页面、Data API、视图、RPC 或对象路径访问时只看到可发布字段。已下架内容退出检索与缓存 |
| 两账号与浏览器切换 | A 的收藏、拒绝、记忆、会话、签名文件与工具结果对 B 不可见。会话重置或注销后的晚响应被丢弃 |
| 评测与同版本竞争 | 用户答题后看见待确认差异。跳过继续浏览。两个标签页确认同一版本只生效一次，版本冲突需展示新差异。删除后下轮无旧记忆 |
| 单词、否定与复合意图 | “沙发”直接返回首批结构化列表。少于 20 则如实显示。“不要皮的，比较刚才两款，再找更便宜的”保留排除、引用和任务依赖 |
| 重试、分页和撤回 | 相同请求键重放，同键不同负载冲突。不同页无重复。失效游标可恢复，已下架结果不会因旧索引被再次返回 |
| 依赖故障与成本 | 模型不可用时，受限公共查询可降级或发一个澄清。数据库故障与无结果区分。记录每段耗时、首个可用事件、Token、模型调用次数和费率 |
| 工具与任务恢复 | 跨用户 ID、越权工具、私网链接和提示注入样例均被拒绝或作为数据处理。取消、重投和重启按尝试号恢复，无重复可见副作用 |
