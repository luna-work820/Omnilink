# 文章页批注修订

按本轮七处批注实现，方向为简约 Notion 风格，ENERGY 1 / RHYTHM 1 / MOTION 1。继续在实现中应用已确认的 antislop 规则。

## 结果

1. 移除正文聚焦时包围整个编辑区的蓝色外框，保留编辑光标及其他控件的键盘焦点。
2. 移除顶部“部件”按钮；斜杠菜单和正文侧边的添加、拖动入口保留。
3. 背景改为可展开色盘，提供默认背景和 24 种 Radix 浅色，选中状态带勾选标记。
4. 预览展开双栏，左侧仍可编辑，右侧为独立可滚动的手机阅读视图。两侧同步标题、正文、封面、背景和商品卡片。
5. 标题上方添加横幅封面，支持上传、更换、调整位置及移除。布局采用参考图的顶部横幅与下方正文结构。
6. 删除“作品发布”和“框架预览”顶部区域，保留三种发布类型页签。
7. 增加专门的商品链接块，通过 `/商品` 插入。支持链接、名称、价格和图片，编辑时打开卡片表单，手机阅读时显示可访问链接。

## 实现决定

- 封面横跨文章宽度，正文继续内缩排版，以区分封面与写作区域。
- 商品卡片使用矩形轮廓、图片和真实填写内容，不使用药丸形卡片；主要操作沿用项目药丸形按钮。
- 预览采用独立的只读 BlockNote 实例同步文档，避免两个视图争用同一编辑器实例。
- 草稿数据更新为版本 2，兼容此前的背景标识和草稿。封面、裁切位置及自定义商品块一起保存。
- 商品卡片只接受 http 或 https 链接；不会显示通用文件工具栏。
- 尚未接入正式发布，发布检查对话框保留明确的框架预览说明。
