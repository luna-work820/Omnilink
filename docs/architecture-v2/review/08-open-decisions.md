# 08 尚未确定的关键决策

以下均为【? 决策】。绿色模块继续作为产品职责。本表中的建议是试验或设计起点。

| 待决项 | 比较选项和建议起点 | 确认所需证据 | 建议决策方与门槛 |
| --- | --- | --- | --- |
| ? 实体模型范围与标识 | 先定类型化公共引用和发布投影。实际需要跨类型外键时再选实体注册表。商品、服务、内容、创作者的公开字段与首批类型分别确认 | 用无商品关联内容、门店服务、SKU 及多来源冲突验证引用和撤回 | 产品与数据。契约冻结前 |
| ? 扩展领域与更多记忆类型 | 活动、场景、地点、个人知识库、素材库分别评估。附件与知识记录保持各自权限，长期偏好继续走确认 | 真实用例、资料保留与访问边界、跨类型关联需求 | 产品与隐私。扩类型前 |
| ? Mastra 深度 | 先用 Workflow 处理一条已知多步路径。动态 Agent 通过有限工具和成本试验 | 固定流程与 Agent 的成功率、证据准确率、工具次数、费用和取消能力 | 工程与产品。启用 Agent 前 |
| ? 新 Agent 及功能优先级 | 空间设计、试穿、搭配等逐项比较是否有足够商品数据、参考素材和需求 | 可复现的场景、来源和视觉效果评估，单任务成本和预期价值 | 产品。扩展能力前 |
| ? 轻量分类器和预算 | 区分分类模型与回复模型。选模型前比较结构准确率、否定、多意图、指代、冷启动及费用 | 冻结查询集、混淆矩阵、P50/P95、每有效请求费用、规则降级结果 | 工程与产品。自然语言试点前 |
| ? 游客额度和 BYOK 策略 | 公开浏览、可限量体验、登录或自带 Key 三种权限场景分开。明确谁承担模型费用与取消后结算 | 审查真实部署代理信任链，试算滥用上限，确定凭据轮换与可用性 | 产品、安全与成本负责人。开放模型前 |
| ? 长期记忆旧数据与撤销删除 | 对旧问卷、手动事实、自动推断按来源分层回填。确认哪些记录需再次授权，撤销和删除保留期分别定义 | 旧数据抽样、确认历史证据、删除传播演练和双标签页冲突 | 产品与隐私。迁移和激活前 |
| ? 价格和多币种 | 同币种严格比较或引入经确认 FX 快照。定义询价、免费、未知与在售变体 | 典型价格样例和汇率时效，避免硬预算违规 | 产品与目录负责人。跨币种前 |
| ? 分页与行为自适应参数 | 以首批 20 为默认。评估有限搜索运行快照与键集游标。后续页量、停留阈值和提问冷却需要试点 | 供给数量、图片预算、翻页去重、有效探索率和提问干预率 | 产品与工程。自适应前 |
| ? 行为事件与数据保留 | 先采集最少的会话行为。确认是否将长期行为提案、遥测及供应商调用关联到个人 | 合意范围、保留期、可撤回和删除测试、供应商数据策略 | 产品、隐私与安全。收集前 |
| ? 缓存与 Redis | 先用请求合并及可撤回的公开版本缓存。比较平台准入、Postgres 原子计数与共享缓存 | 多实例额度正确性、缓存命中、撤回延迟及实测 DB 等待 | 工程。放量前按数据选择 |
| ? 异步任务与 worker | 现有 Postgres 租约表、Supabase Queues 或专用队列。Mastra 持久存储与产品任务状态分别评估 | 进程重启、租约超时、取消、重投、排队延迟和预算 | 工程与运维。长任务前 |
| ? 嵌入及外部来源 | BGE 常驻或托管嵌入、关键词首发、获准外部来源范围、同一实体合并规则 | 目标环境模型封装、HNSW 召回与延迟、合法来源与覆盖、下架后的失效 | 数据与工程。语义和多源上线前 |
| ? 生产监控与服务等级 | 先定义脱敏事件和首个有效结果，再决定追踪、告警平台与费用阈值 | 实测关键路径和异常流量、恢复演练、Token 和对象存储开销 | 工程、运维与成本负责人。放量前 |

已确认的固定 AI 聊天框、可跳过评测、首批 20 件及确认后写入记忆在本表中作为约束。
