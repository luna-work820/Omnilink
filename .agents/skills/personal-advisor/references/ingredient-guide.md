# 成分功效库

按用户档案的主要问题选成分。每个成分写四项：中文名与 INCI 名、主要作用、常见有效浓度范围、使用注意。浓度一律写范围并标注为范围参考，不写具体数值。

## 控油与疏通

- 水杨酸 / Salicylic Acid：脂溶性酸类，深入毛囊溶解油脂、疏通堵塞。常见有效浓度范围 0.5%—2%。油性及痘痘肌适用。注意避开眼周，敏感肌慎用，不与视黄醇同晚高浓度叠加。
- 果酸 / Glycolic Acid、乳酸 / Lactic Acid：果酸分子量小，乳酸刺激性较低。常见有效浓度范围 5%—40%，家用上限通常更低。用于改善纹理与角质堆积。注意建立耐受，敏感肌从低浓度开始。
- 锌 / Zinc PCA、ZnO：抑制皮脂分泌，用于控油与抑菌。常见有效浓度范围 1%—5%。性质温和，适合油性肌。
- 透明质酸 / Hyaluronic Acid：抓取皮肤表层水分。常见有效浓度范围 0.1%—2%。分子量越大越在表层成膜，越小渗透越深。单独使用可能反而带走皮肤水分，需搭配封闭剂。

## 保湿与修护

- 神经酰胺 / Ceramide NP、AP、EOP：角质层脂质的核心组成，补充后加固屏障。常见有效浓度范围 0.5%—5%。适合屏障受损、换季泛红。所有肤质可用。
- 胆固醇 / Cholesterol、脂肪酸 / Free Fatty Acids：与神经酰胺协同构成屏障脂质，常见有效浓度范围 1%—5%。常与神经酰胺复配出现。
- 角鲨烷 / Squalane：结构接近皮脂的封闭剂，形成保湿膜。常见有效浓度范围 5%—20%。干性、油性、敏感肌通用，不闷痘。
- 甘油 / Glycerin：吸湿性保湿剂。常见有效浓度范围 5%—15%。浓度过高会黏腻。
- 泛醇 / Panthenol：维生素 B5 前体，促屏障修复、舒缓。常见有效浓度范围 1%—5%。敏感肌友好。
- 积雪草苷 / Madecassoside：抗炎舒缓，适合泛红、换季不稳定、医美术后。常见有效浓度范围 0.1%—1%。
- 胆碱 / Choline：舒缓类，通常与积雪草苷复配。

## 美白与色沉

- 烟酰胺 / Niacinamide：抑制黑色素转运至角质层，兼顾控油与屏障。常见有效浓度范围 2%—10%。4% 以上抗炎作用更明显。高浓度不耐受者会红肿刺痛，部分人反馈长期使用汗毛加重。
- 抗坏血酸 / Ascorbic Acid：抗氧化并抑制黑色素生成。常见有效浓度范围 8%—20%。易氧化，需避光保存和避光使用，敏感肌选衍生物如抗坏血酸葡糖苷。
- 传明酸 / Tranexamic Acid：阻断黑色素传递通路，对炎症后色沉和顽固色斑更有针对性。常见有效浓度范围 2%—5%。性质温和，敏感肌可用。凝血功能障碍者避免使用。
- 熊果苷 / Alpha Arbutin：抑制酪氨酸酶活性，减少黑色素生成。常见有效浓度范围 1%—7%。性质温和。
- 谷胱甘肽 / Glutathione：抗氧化并抑制黑色素合成，常见有效浓度范围 1%—5%。
- 防晒剂 / UV Filters：氧化锌、二氧化钛属于物理防晒剂；阿伏苯宗属于化学防晒剂。防晒是美白的前提，不防晒时美白效果有限。物理防晒剂可能泛白。

## 抗老与紧致

- 视黄醇 / Retinol 及视黄醛 / Retinal：促进胶原生成，淡化细纹。常见有效浓度范围 0.1%—1%。视黄醛刺激性低于视黄醇。孕妇与哺乳期禁用。需要夜间使用并逐步建立耐受，初期可能干燥脱皮。
- 视黄醇棕榈酸酯 / Retinyl Palmitate：刺激性更低，活性弱于视黄醇，浓度常需更高。
- 胜肽 / Peptides：信号传导类，促胶原生成。常见有效浓度范围 1%—5%。温和，敏感肌可用。
- 玻色因 / Pro-Xylane：促糖胺聚糖合成，增强皮肤支撑力。常见有效浓度范围 3%—10%。温和，适配性广。
- 腺苷 / Adenosine：舒缓与抗皱类，常见有效浓度范围 0.04%—0.1%。

## 祛痘

- 壬二酸 / Azelaic Acid：抗菌、抗炎、淡化痘印，对痤疮相关色沉同时有效。常见有效浓度范围 10%—20%。刺激性低于水杨酸，适合敏感型痘痘肌。初期可能有轻微刺痛感。
- 过氧化苯甲酰 / Benzoyl Peroxide：抗菌作用强，对炎性痘有效。常见有效浓度范围 2.5%—10%。会氧化衣物，可能刺激皮肤。

## 常见搭配与冲突

可搭配：烟酰胺与神经酰胺；烟酰胺与传明酸；水杨酸与神经酰胺；透明质酸与角鲨烷；积雪草苷与任何功效成分。

不建议同晚叠加：水杨酸与视黄醇；高浓度维C与视黄醇；多种酸类同时；壬二酸与高浓度酸类。

分时段使用：水杨酸与视黄醇可分早晚；维C早上用，视黄醇晚上用。

## 特殊人群

孕妇与哺乳期：禁用视黄醇类与维A酸类。四氢姜黄素、烟酰胺、神经酰胺、传明酸相对稳妥，但仍建议先咨询医生。

敏感肌：优先屏障修护类，避免香精、乙醇、高浓度酸类。功效成分一次只加一个，观察两周再加下一个。

油痘肌：避免厚重封闭剂与高致痘风险油脂。
