# 肤质档案库

依据第二步确认结果选取对应档案。档案内容作为模板使用，其中的成因推测必须标注为推测。

## 肤质编码

肤质档案由四个维度组合而成，输出时按此顺序叙述。

### 维度一 · 基础型

四选一：油性 / 干性 / 中性 / 混合性。

敏感不是独立的基础型而是状态，见维度三。

### 维度二 · 混合性亚型与出油范围

基础型为混合性时必须确认亚型与出油范围，其他基础型不适用。

亚型二选一：

- T 区型：T 区油、U 区干，分区界限全年基本固定。
- 季节型：随季节移动。常见夏油冬干，也有少数夏干冬油。

出油范围四选一：仅 T 区出油 / 局部出油（鼻翼、下巴为主）/ 全脸均匀出油 / 全脸均匀干燥。

用户选局部出油并指明具体部位时，按鼻翼为主或下巴为主记录。用户选全脸均匀出油或全脸均匀干燥时，归为油性或干性基础型，不按混合性处理。

用户说不清具体部位时按仅 T 区出油处理，并在输出中说明这是按最常见情况归类。

鼻部皮脂腺密度可达面颊的五至八倍，这是 T 区与两颊出油差异的结构性原因，不是护理不当造成的。输出中说明这一点，避免用户误以为护理失败。

### 维度三 · 敏感程度与水油状态

敏感程度四选一：从未泛红刺痛 / 偶尔泛红刺痛 / 明显泛红脱屑 / 皮肤状态不稳定期。

水油状态二选一：正常 / 外油内干。外油内干指 T 区有油光但角质层实际缺水，两种表现同时存在。

这两个维度与基础型正交，可叠加在任何基础型上。

### 输出格式

档案标题按"基础型 · 亚型 · 敏感程度 · 水油状态"排列。亚型与水油状态不适用时省略该项。

示例：混合性 · T 区型 · 偶尔泛红刺痛 · 外油内干。

## 油性

水油特征：全脸出油，T 区与两颊出油量接近或 T 区更明显。毛孔在鼻翼与额头可见。肤色偏红润，油光明显。

常见问题与推测成因：毛孔粗大（推测与皮脂分泌量及角质堆积有关）；粉刺（推测与毛囊皮脂腺导管阻塞有关）；脱妆（推测与出油速度超过吸油速度有关）。

规避成分类型：高致痘风险油脂如椰子油、肉豆蔻酸异丙酯；高浓度酒精；厚重封闭剂。

步骤顺序：温和清洁 → 控油化妆水 → 水杨酸类疏通 → 清爽保湿 → 白天防晒。

观察节点：四周后看毛孔与粉刺变化，八周后看出油量变化。

## 干性

水油特征：两颊与下巴干燥，T 区出油很少或不出油。皮肤缺乏光泽，常见细小干纹。毛孔不明显。

常见问题与推测成因：脱屑（推测与角质层含水量不足有关）；紧绷感（推测与屏障脂质流失有关）；细纹明显（推测与长期缺水有关）。

规避成分类型：皂基清洁剂；高浓度酒精；无保湿能力的轻薄质地基底。

步骤顺序：温和清洁 → 保湿水或精华 → 修护精华 → 厚重保湿霜 → 白天防晒。

观察节点：四周后看脱屑与紧绷感，八周后看细纹可见度变化。

## 混合性 · T 区型

水油特征：T 区为额头、鼻部、下巴构成的 T 形区域，出油明显、毛孔较粗、易有黑头；U 区为双颊、颧骨及太阳穴，细腻但易干燥、换季紧绷。分区界限全年基本固定。

常见问题与推测成因：T 区毛孔与粉刺（推测与该区皮脂腺密度高有关）；U 区干燥脱屑（推测与该区角质层较薄、屏障脂质含量较低有关）；护理矛盾导致反复（推测与全脸使用同一产品有关）。

分区护理：T 区按油性护理，U 区按干性护理。全脸使用同一产品必然顾此失彼，这是本型最主要的护理误区。

规避成分类型：全脸高浓度酸类；全脸高浓度视黄醇；厚重封闭剂用于 T 区。

步骤顺序：温和清洁 → T 区控油 → U 区保湿 → 分区精华 → 白天防晒。

观察节点：四周后看两区状态差异，六周后看分区是否趋于平衡。

## 混合性 · 季节型

水油特征：随季节移动，最常见为夏季偏油、冬季偏干；少数为夏季偏干、冬季偏油。同一个人在一年中可能跨越多个基础型。

常见问题与推测成因：夏油冬干时冬季屏障脂质流失加快（推测与空气湿度下降有关）；夏油冬干时夏季出汗增加使出油更明显（推测与汗液蒸发受阻有关）。

护理要求：按当季实际状态选择方案，不套用固定分区。本型的核心风险是把 T 区型的分区护理全年照搬，导致冬季两颊持续受损或夏季 T 区过度控油。

季节方案：

- 春：换季期泛红刺痛反馈增多，屏障状态波动。加强屏障修护，功效成分降低起始浓度。
- 夏：控油与清爽保湿并重，强调防晒用量与补涂。酸类可维持，注意出汗后叠加刺激。
- 秋：外油内干加重，色素沉着倾向更明显。加强保湿封闭，美白成分配合防晒。
- 冬：干燥脱屑紧绷加重，屏障脂质流失加快。以修护屏障为核心，质地偏厚，功效成分暂停或降至最低浓度。

步骤顺序：温和清洁 → 按当季选质地 → 功效性产品按当季耐受度调整 → 白天防晒。

观察节点：每季转换后重新评估基础型，肤质可能随季节改变。

## 中性

水油特征：全脸水油平衡，T 区与两颊差异不明显。毛孔细腻，肤色均匀。

常见问题与推测成因：局部偶发干燥或出油（推测与季节和作息有关）。

规避成分类型：无特殊规避。

步骤顺序：温和清洁 → 保湿 → 功效性产品按需 → 白天防晒。

观察节点：按季节变化复看。

## 敏感维度

敏感可叠加在任何基础型上。敏感程度越高，功效性成分的起始建议越保守，质地越简单。

从不泛红刺痛：可正常引入功效性成分，注意逐步建立耐受。

偶尔泛红刺痛：功效成分从最低浓度开始，一次只加一种。

明显泛红脱屑：以屏障修护为核心，暂停全部功效性成分，质地精简。

皮肤状态不稳定期：只输出极简护理方案，不推荐功效性成分。

规避成分类型随程度加深：从不泛红刺痛无额外规避；偶尔泛红刺痛避开香精与高浓度酒精；明显泛红脱屑避开香精、乙醇、高浓度酸类、视黄醇类、皂基清洁剂、甲基异噻唑啉酮、色素。

## 外油内干

T 区有油光但角质层缺水，两颊同时干燥。表现上是油，实质是缺水导致的代偿性出油。

常见问题与推测成因：T 区油光（推测与缺水后的代偿性分泌有关）；两颊干燥（推测与屏障脂质流失有关）。

护理要求：以补水与屏障修护为主，控油为辅。单纯控油会加重代偿。

## 问题专项

档案中针对主要困扰补充对应内容。

出油与毛孔：水杨酸、果酸、锌类。推测成因说明皮脂分泌与毛孔外观的关系。

干燥与脱屑：神经酰胺、胆固醇、游离脂肪酸、角鲨烷、甘油、透明质酸。说明封闭与补水要同时做。

痘痘与痘印：水杨酸、壬二酸、烟酰胺。推测成因说明痘痘与痘印的区别，前者与毛囊阻塞有关，后者与炎症后色素沉着有关。

色斑与暗沉：烟酰胺、维C 及其衍生物、传明酸、熊果苷。强调防晒是前提，不防晒时美白效果有限。

红血丝与泛红：神经酰胺、泛醇、积雪草苷、胆碱。避免功效叠加。

初老与松弛：视黄醇及衍生物、胜肽、玻色因。说明建立耐受的过程。

## 组合规则

基础型与亚型冲突时以亚型为准。混合性季节型在冬季按干性方案处理，不因基础型标注为混合性而沿用分区护理。

肤质与问题冲突时，以问题为主调整顺序。例如敏感同时有抗老需求时，先修复屏障，暂缓高功效成分。

处于皮肤状态不稳定期时，只输出极简护理方案，不推荐功效性成分。

正在使用高功效产品时，不叠加同类功效成分，输出中明确说明。

生理期前常见出油增加与长痘，此为周期性变化，不作为肤质改变处理。

空调环境与供暖环境造成的干燥与季节因素分开说明，不据此改变亚型判定。
